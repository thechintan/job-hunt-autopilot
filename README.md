# Job Hunt Autopilot 🚀

> **Tagline:** Track every application. Catch every fake offer.

A small web app for job seekers who were laid off and now have hundreds of applications and a messy inbox. It classifies emails, builds a live tracker, flags fake offers in red, and drafts follow-up emails.

---

## Quick Start (3 commands)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# (Optional) Copy environment template if using Kaggle credentials
cp .env.example .env

# 2. (Optional) Download ML training data and train the scam model
python -m scripts.download_data
python -m scripts.train

# 3. Run the app
streamlit run app.py
```

Then click **"📂 Load sample inbox"** in the sidebar to see the demo.

---

## Features

| Feature | Details |
|---|---|
| **Email classification** | 6 labels: `applied`, `interview`, `rejected`, `offer`, `scam`, `other` |
| **Scam detection** | Weighted rule signals + optional ML model (TF-IDF + LogisticRegression) |
| **Application tracker** | One row per company/role, state machine for status |
| **Follow-up reminders** | Silent for 7+ days at "applied" → ready-to-copy draft |
| **Hinglish support** | Keyword lists for common Indian-language job scam phrases |
| **Simulate** | Add a new email in-app and watch the tracker update live |

## Datasets (for ML scam model)

The app works **fully offline in rules-only mode** without any datasets. To enable the ML boost:

### Option A: Automatic (requires Kaggle CLI)
```bash
pip install kaggle
# Set up ~/.kaggle/kaggle.json with your API credentials
python -m scripts.download_data
```

### Option B: Manual
1. **Kaggle dataset**: https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction  
   → Place `fake_job_postings.csv` in `data/raw/`
2. **HuggingFace dataset**: Downloaded automatically by `scripts/download_data.py`

Then train: `python -m scripts.train`

## Architecture

```
inbox (.json/.mbox)
   → ingest.py       → list[Email]
   → normalize.py    → company + role extraction
   → classify.py     → 1 label + reasons per email
        ↑ scam_rules.py  (weighted signals)
        ↑ scam_ml.py     (optional ML boost)
   → tracker.py      → list[Application] (state machine)
   → followups.py    → list[FollowUp] (7-day rule)
   → app.py          → Streamlit UI
```
